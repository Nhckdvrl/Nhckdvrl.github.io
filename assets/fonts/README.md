# Self-hosted fonts

All three families are licensed under the SIL Open Font License 1.1
(see the matching `LICENSE-*.txt`). Files come unchanged from Fontsource 5.3.0
via jsDelivr, Latin subset only; CJK text falls back to system fonts.

- `newsreader-latin-opsz-normal.woff2` — Newsreader (Production Type), variable opsz + wght. Headings.
- `inter-latin-wght-normal.woff2` — Inter (Rasmus Andersson), variable wght. Body text.
- `jetbrains-mono-latin-400-normal.woff2` — JetBrains Mono 400. Small labels.
