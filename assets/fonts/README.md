# Self-hosted fonts

Both families are licensed under the SIL Open Font License 1.1
(see the matching `LICENSE-*.txt`). Sources are the Fontsource 5.3.0 Latin files
via jsDelivr, trimmed with fontTools to the ranges the site uses: Newsreader to
weights 300–500, optical sizes 16–72 and Latin, Latin-1 and common punctuation;
Inter to weights 400–700. CJK text falls back to system fonts.

- `newsreader-latin-opsz-normal.woff2` — Newsreader (Production Type), variable opsz + wght (trimmed). Headings.
- `inter-latin-wght-normal.woff2` — Inter (Rasmus Andersson), variable wght (trimmed). Body text and small caps labels.
