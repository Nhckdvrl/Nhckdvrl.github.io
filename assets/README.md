# Site images

The layout already expects these optional image files:

- `profile.jpg` — main portrait/photo used on Home and About.
- `character-1.png` — transparent character sticker decoration.
- `character-2.png` — second transparent character sticker decoration.

If the character files are absent, their decorative elements automatically hide.
If `profile.jpg` is absent, the site falls back to the GitHub avatar.

Recommended:
- profile.jpg: ~1200×1500, JPEG/WebP
- character PNGs: transparent background, 300–700px on the long side
